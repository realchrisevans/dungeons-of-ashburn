# Dungeons of Ashburn

A pixel-art, side-scrolling dungeon crawler being developed
as a solo learning project with Godot and GDScript.

Explore dangerous ruins, fight monsters, and uncover their history.

## Development Status

Early movement prototype. Combat, enemies, bosses, and final
artwork are planned but are not implemented yet.

Currently implemented:
- Horizontal player movement.
- Jumping and gravity.
- Floor collision.
- Automatic reset after falling out of the test room.
- Colored placeholder floor.
- Left and right room boundaries.

The prototype currently uses placeholder graphics.

## Controls

| Action | Keys |
|--------|------|
| Move left | A / Left Arrow |
| Move right | D / Right Arrow |
| Jump | Space |

## Running the Project

1. Download or clone this repository.
2. Open Godot 4.7.2 Standard.
3. Import `game/dungeonproject/project.godot`.
4. Open `res://scenes/levels/test_room.tscn`.
5. Press F6 to run the test room.

## Platforms

- Current development target: Windows.
- A browser-playable version is planned.
